# 开发指南

## 环境准备

### 1. Python 环境

需要 Python 3.10+。建议使用 conda 或 venv 管理虚拟环境：

```bash
# conda 方式
conda create -n webdev python=3.11
conda activate webdev

# venv 方式
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Linux/Mac
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动服务

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload --root-path /api
```

服务默认监听 `0.0.0.0:8000`，所有 API 端点会自动添加 `/api` 前缀。

## 项目架构

```
litestar/
├── main.py              # 应用入口（配置、路由注册）
├── routers/             # 业务路由模块
│   ├── __init__.py
│   ├── user.py          # 用户管理路由
│   └── system.py        # 系统路由
├── models/              # 数据模型
│   ├── __init__.py
│   └── user.py          # 用户相关模型
├── docs/                # 开发文档
└── requirements.txt     # Python 依赖
```

### 目录说明

| 目录 | 说明 |
|------|------|
| `main.py` | 应用入口，负责应用配置和路由注册 |
| `routers/` | 存放所有业务路由，按功能模块拆分 |
| `models/` | 存放 Pydantic 数据模型 |
| `docs/` | 开发文档 |

## 如何添加新端点

### 方式一：创建新的路由文件（推荐）

适合业务模块，按功能拆分：

**步骤 1**：在 `models/` 下创建数据模型，如 `models/weather.py`：

```python
from pydantic import BaseModel, Field
from typing import Optional

class WeatherRequest(BaseModel):
    """天气查询请求"""
    station_id: str = Field(description="站点ID")
    date: Optional[str] = Field(None, description="查询日期")


class WeatherResponse(BaseModel):
    """天气响应"""
    station_id: str
    temperature: float
    humidity: int
```

**步骤 2**：在 `routers/` 下创建路由文件，如 `routers/weather.py`：

```python
from litestar import get, post
from typing import List
from models.weather import WeatherRequest, WeatherResponse

@get("/api/weather/current", tags=["气象服务"], summary="获取当前天气")
async def get_current_weather(station_id: str) -> WeatherResponse:
    """获取指定站点的当前天气数据"""
    return WeatherResponse(
        station_id=station_id,
        temperature=25.6,
        humidity=65
    )
```

**步骤 3**：在 `routers/__init__.py` 中导出：

```python
from .user import list_users, get_user, create_user, update_user, delete_user
from .system import health_check
from .weather import get_current_weather

__all__ = [
    "list_users",
    "get_user",
    "create_user",
    "update_user",
    "delete_user",
    "health_check",
    "get_current_weather",  # 新增
]
```

**步骤 4**：在 `main.py` 中导入并注册：

```python
from routers import (
    list_users,
    get_user,
    create_user,
    update_user,
    delete_user,
    health_check,
    get_current_weather,  # 新增
)

app = Litestar(
    route_handlers=[
        # ... 其他路由
        get_current_weather,  # 新增
    ],
)
```

### 方式二：直接在 main.py 添加

适合简单或系统级端点：

```python
@get("/api/my-endpoint", tags=["我的模块"], summary="接口说明")
async def my_endpoint(name: str) -> dict:
    return {"message": f"Hello {name}"}
```

## 数据模型定义

在 `models/` 目录下定义所有 Pydantic 模型：

```python
from pydantic import BaseModel, Field
from typing import Optional, List

class MyModel(BaseModel):
    """模型说明"""
    id: int = Field(description="唯一标识")
    name: str = Field(description="名称")
    tags: Optional[List[str]] = Field(None, description="标签")
```

## 静态资源

 Knife4j Vue3 前端编译产物位于 `E:\Devs\knife4j-vue3\dist\`。

本项目通过 `STATIC_DIR` 变量引用该目录：

```python
STATIC_DIR = os.path.abspath(os.path.join(os.path.dirname(__file__), "../../dist"))
```

如果 Knife4j 页面显示异常，请确保：

1. 已执行 `pnpm build` 编译 knife4j-vue3 前端
2. 编译产物在 `E:\Devs\knife4j-vue3\dist\` 目录下
