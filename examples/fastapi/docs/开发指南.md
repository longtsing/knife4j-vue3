# 开发指南

## 环境准备

### 1. Python 环境

需要 Python 3.10+。建议使用 conda 或 venv 管理虚拟环境：

```bash
# conda 方式
conda create -n webdev python=3.11
conda activate webdev

# venv 方式
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Linux/Mac
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动服务

```bash
python main.py
```

服务默认监听 `0.0.0.0:8000`。

## 项目架构

```
fastapi/
├── main.py              # 应用入口（配置、中间件、系统端点）
├── routers/             # 业务路由模块
│   ├── __init__.py
│   └── test.py          # 测试路由器示例
├── statics/             # Knife4j Vue3 静态资源（勿修改）
├── docs/                # 开发文档
└── requirements.txt     # Python 依赖
```

### main.py 职责

`main.py` 是应用入口，按以下顺序组织：

| 区块 | 说明 |
|------|------|
| 配置常量 | `ROOT_PATH`、`PORT`、`STATIC_DIR` 等 |
| FastAPI 实例 | 应用配置（标题、文档、认证等） |
| 中间件 | CORS 跨域、Basic Auth 认证 |
| Knife4j 路由 | `/doc.html`、`/v3/api-docs/swagger-config` |
| 系统端点 | `/version`、`/health` |
| 业务路由 | 从 `routers/` 引入 |
| 静态资源 | `app.mount("/", ...)` 兜底 |

**关键规则**：`app.mount()` 必须放在所有路由之后，否则会拦截 API 请求。

## 如何添加新端点

### 方式一：直接在 main.py 添加

适合系统级或少量端点：

```python
@app.get("/my-endpoint", tags=["我的模块"], summary="接口说明")
async def my_endpoint(param: str = Query(description="参数")):
    return {"data": param}
```

### 方式二：创建新的路由文件（推荐）

适合业务模块，按功能拆分：

**步骤 1**：在 `routers/` 下创建文件，如 `routers/weather.py`：

```python
from fastapi import APIRouter, Query
from typing import Optional

router = APIRouter(tags=["气象服务"])


@router.get("/api/weather/current", summary="获取当前天气")
async def get_current_weather(
    station_id: str = Query(description="站点ID")
):
    """获取指定站点的当前天气数据"""
    return {
        "station_id": station_id,
        "temperature": 25.6,
        "humidity": 65
    }


@router.get("/api/weather/history", summary="获取历史天气")
async def get_history_weather(
    station_id: str = Query(description="站点ID"),
    start_date: str = Query(description="开始日期 YYYY-MM-DD"),
    end_date: str = Query(description="结束日期 YYYY-MM-DD")
):
    return {"station_id": station_id, "data": []}
```

**步骤 2**：在 `main.py` 中引入：

```python
from routers.weather import router as weather_router
app.include_router(weather_router)
```

## API 文档（Knife4j）

### 访问方式

浏览器访问 `http://localhost:8000/doc.html`，输入账号密码即可查看和调试 API。

### 工作原理

1. FastAPI 自动生成 OpenAPI JSON（`/api/openapi.json`）
2. Knife4j Vue3 前端通过 `/v3/api-docs/swagger-config` 获取文档配置
3. `doc.html` 加载静态资源渲染交互式文档界面

### 认证保护

文档路径受 Basic Auth 保护，配置在 `auth_middleware` 中：

```python
credentials = {
    "admin": "admin12345",
}
```

## 常见问题

### Q: 端点添加后文档不显示？

检查是否至少有一个带查询参数的端点。Knife4j 解析器需要 `parameters` 字段来正常渲染。

### Q: 静态资源 404？

确认 `app.mount("/", ...)` 在所有 `@app.get()` 路由之后。

### Q: 如何修改端口？

修改 `main.py` 底部：

```python
uvicorn.run(app, host="0.0.0.0", port=8000)  # 改为你需要的端口
```

### Q: 如何修改反向代理前缀？

修改 `main.py` 顶部常量：

```python
ROOT_PATH = '/api'  # 改为你的前缀
```
